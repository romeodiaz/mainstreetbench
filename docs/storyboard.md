# Simple video plan

Show how you choose a useful task, test an AI setup and check the work.

| Part | What to show | What to say |
|---|---|---|
| The job | Bakery spreadsheet and prompt | “I built a personal AI test around a job a small business might actually need done.” |
| The run | Model settings, timer and a few working moments | “The AI gets the spreadsheet and prompt. It doesn’t get the answer key.” |
| The output | Customer list and dashboard | “Here’s what it made.” |
| The check | Separate grader, key and results | “It found or flagged all 12 problem types, but the money total was still $27 too high.” |
| The takeaway | Repository link | “The prompt, answer key, outputs and scoring are all here. Check my work or try your own setup.” |

Use the actual results, count any help given and label sped-up footage. Show the prompt version: both completed runs used v0.1; future runs use v0.2.

Link the repository directly in the caption or description. Viewers should not need to comment or sign up to see the evidence.

The [original recording plan](archive/recording-plan.md) describes a future three-app comparison. It is a plan, not a completed result.
